    如何閱讀與替換案例

    本頁重播 Python 演算法產生的紀錄，不在瀏覽器重新計算路由。每個 EXTEND 分成「延伸檢查」與通過後的「支配比較／入隊」兩個展示步驟；資料來自同一筆 trace。搜尋步驟的播放速度不代表網路時間。

    同一 Contact 的開始時間逐格枚舉；前段失敗仍會嘗試後段。建立 Label 時檢查本次傳送及接收，接收端後續等待在延伸下一跳時檢查。支配需同節點、較早抵達、各 Contact 用量不更多，且能持包等到另一 Label 的抵達時間。

    Label 使用 c/A/s/pred 四欄位；Contact ID 與 Label ID 各自編號。核心用量快取由前驅鏈推導，沒有新增 U 欄位。此版本是有限格點、aggregate 容量模型，未加入鏈路時段互斥，不等同實體網路排程驗證。閱讀繁體中文逐行註解。

    更換拓樸或演算法後，先在 Python 產生並驗證結果，再使用 python -m src.experiments.export_website --run 結果資料夾 --title 案例名稱 --output replay.json 匯出，於本頁匯入。請匯入本專案匯出格式。

    互動呈現參考 Adrian Haarbach 的 SPPRC 示範；本頁使用專案自己的 DTN 判別與執行紀錄。
