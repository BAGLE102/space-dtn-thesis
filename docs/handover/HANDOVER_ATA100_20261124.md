## 30 系統模型（SYSTEM MODEL）

### 30-00-00 P1 說明與運作

- **符號：** 見 00-20-00。中繼上三個時刻：h = s₁ + d₁（開始收）、A = h + τ₁（收完）、f = s₂ + τ₂（送完）。
- **ramp(t, a, b)：** 從 a 到 b 由 0 線性升到 S，表示到 t 為止已傳的量。

### 30-10-00 一包的占用

| 節點 | own(t) | 期間 |
|---|---|---|
| 來源 | S − ramp(t, s₁, s₁ + τ₁) | [g, s₁ + τ₁] |
| 中繼 | ramp(t, h, A) − ramp(t, s₂, f) | [h, f] |
| 目的地 | ramp(t, h, A)；在 A 交付（左極限 S、右極限 0） | [h, A] |

中繼斜率 = 進的速率 − 出的速率，這就是老師說的 Buffer 變化率。

### 30-20-00 問題定義

- **決策變數：** 路徑 c₁ … c_k 與發送起點 s₁ … s_k。
- **目標：** min Arr = s_k + τ_k + d_k。

| 限制 | 內容 |
|---|---|
| 路徑 | 接得起來；**節點不重複**（2026-11-23 使用者決定完全禁止重訪） |
| 時間 | a ≤ s，s + τ ≤ b；s₁ ≥ g；Arr ≤ T |
| 連線獨占 | 不與已預約時段重疊 |
| 轉發 | s₂ ≥ s₁ + d₁ + lag |
| Buffer | 每個節點、每一刻 O_n(t) + own(t) ≤ M；跳變處左右極限都要成立 |

### 30-30-00 轉發規則

- **lag：** 邊收邊轉 lag = max(0, τ₁ − τ₂)；收完才轉 lag = τ₁。
- **兩者共存：** 收完才轉的排程都滿足邊收邊轉的條件，所以邊收邊轉模式是「能邊收邊轉就邊收邊轉，下一條連線沒開就自動先存」。
- **目前限制：** 整個網路使用同一個設定（`P.ct`）。

### 30-40-00 前提

- **背景契約：** 任何時刻 O_n(t) ≤ M。
- 違反時（例如格點驗證的案例 2663），`own = 0` 的跳過檢查不再精確。

### 40-10-00 O_n（占用曲線）

- **存法：** 三個清單 ts（時刻）、ls（左極限）、rs（右極限）；兩點之間是直線。斜率由相鄰兩點算出，不另外存。
- **操作：** `left`、`right`、`top`、`between`、`peak`、`add`（變化點聯集，左加左、右加右）、`prune`。

### 40-20-00 Buffer 檢查

1. **粗篩：** 視窗內舊占用峰值 + S ≤ M，成立就整段保留。

   | 節點 | 視窗 |
   |---|---|
   | 來源 | [g, hi + τ₁] |
   | 中繼 | [L1.lo + d₁, hi + τ₂] |
   | 目的地 | [lo + d, hi + d + τ] |

2. **細篩（`solve_region`）：**
   - 以新包轉折點碰到舊變化點的位置當切點。中繼的切點是 x、x − τ₂、x + lag、x + lag − τ₁，再加上 clamp。
   - 段內合計是開始時間 s 的一次函數 v(s) = a + k·s，解 v(s) ≤ M 得上界或下界。
   - 程式以段內兩個非端點的點（1/3、2/3 位置）代入求 a、k：這是 AI 寫程式時的實作細節，不是方法的一部分，不得寫進論文或簡報當成方法。
   - 切點本身用規則直接檢查。
3. **中繼的關鍵性質：** 固定 s₂，只測最晚的 s₁* = min(L1.hi, s₂ − d₁ − lag)。s₁ 越晚，中繼的占用處處不增，所以二維問題變一維。
4. **全部用分數（Fraction）精確計算。**

### 40-30-00 搜尋

- **佇列鍵：** lo + τ + d。
- **去重：** `reached[c]` 記錄連線 c 已放過的區間，新區間先扣掉。
- **展開：** head = L1.lo + d₁ + lag → `candidate_range` → `buffer_filter` →（若到目的地）`destination_filter` → `insert`。
- **不重複節點：** 跳過 `c₂.v ∈ path_nodes(L1)`。

### 40-40-00 回推

最後一段取 lo；往前 s_i = min(L_i.hi, s_{i+1} − d_i − lag)。前段取最晚，讓包在中繼停留最短。

### 40-45-00 標準算例（簡報與文件都用這組）

**設定**
- A→B 100–150 秒，1 MB/s；B→C 110–160 秒，0.5 MB/s；A→C 150–200 秒，1 MB/s。
- S = 10 MB，g = 100；B 的上限 M = 12，舊占用 [100:0, 110:10, 120:10, 130:0]；延遲 0，邊收邊轉。

**過程**
- 初始佇列：A→B [100, 140]，鍵 110；A→C [150, 190]，鍵 160。
- 展開 B→C：candidate [110, 140]；粗篩 20 > 12；細篩得 [116, 140]（關鍵：t = 120 時 70 − 0.5s ≤ 12）。

**結果**
- 回推 c₁ = c₂ = 116，C 在 136 秒收完；B 更新為 [100:0, 110:10, 116:10, 120:12, 126:9, 130:3, 136:0]。
- 可重現：用 `src/algorithm` 建立這組 Problem 執行 `ours.plan`。
